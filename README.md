# star-banner-shop-proxy

Тонкий прокси на Vercel — весь трафик прозрачно проксируется на настоящий
бэкенд на Railway (`https://star-banner-shop-production.up.railway.app`),
чтобы получить короткую бесплатную ссылку вида `имя.vercel.app` вместо
длинного адреса Railway.

Никакой логики здесь нет: только `vercel.json` с правилом rewrite на все пути.
Сайт, админка и бот по-прежнему живут и работают на Railway — здесь просто
"вывеска" с коротким именем.

## Деплой

1. На [vercel.com](https://vercel.com) — Add New → Project → Import из этого
   репозитория.
2. При настройке проекта укажите желаемое короткое имя проекта (оно и станет
   доменом: `имя.vercel.app`). Если имя занято, Vercel предложит альтернативу.
3. Framework Preset — Other. Никаких переменных окружения и build-команд не
   нужно.
4. Deploy.

Если адрес бэкенда на Railway изменится (например, при пересоздании сервиса),
обновите `destination` в `vercel.json` и задеплойте заново.
